Naš projekt zajema razvoj spletne trgovine za prodajo oblačil, ki bo uporabnikom omogočala spletno nakupovanje. 
Uporabniki bodo lahko pregledovali ponudbo oblačil, iskali in filtrirali izdelke, si ogledali njihove podrobnosti ter jih dodajali v košarico. 
Trgovina bo omogočala tudi registracijo in prijavo uporabnikov ter izvedbo spletnega plačila. 

Cilj projekta je izdelati sodobno, uporabniku prijazno in funkcionalno spletno trgovino.
