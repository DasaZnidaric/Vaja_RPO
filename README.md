# Spletna trgovina z oblačili

## Opis projekta

Naš projekt je spletna trgovina za prodajo oblačil, ki uporabnikom omogoča enostavno in pregledno spletno nakupovanje. Uporabniki bodo lahko pregledovali ponudbo oblačil, iskali in filtrirali izdelke, si ogledali njihove podrobnosti ter jih dodajali v nakupovalno košarico. Trgovina bo omogočala registracijo in prijavo uporabnikov ter izvedbo spletnega plačila.

## Glavne funkcionalnosti

- Registracija in prijava uporabnikov.
- Pregled vseh oblačil.
- Iskanje in filtriranje izdelkov.
- Ogled podrobnosti posameznega izdelka.
- Dodajanje in odstranjevanje izdelkov iz košarice.
- Spreminjanje količine izdelkov v košarici.
- Izvedba spletnega plačila.
- Administracija izdelkov in naročil.

## Uporabljene tehnologije

- **Frontend:** Angular
- **Oblikovanje:** HTML, CSS, Bootstrap
- **Backend:** Node.js
- **Podatkovna baza:** MySQL
- **Verzioniranje kode:** Git, GitHub
- **Organizacija dela:** Trello
